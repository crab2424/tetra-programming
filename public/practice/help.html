GOAL
  • NONE / LINES・PUYOS / SCORE / TIME から選べる。VALUE で目標値を設定する
  • 目標を達成すると、続けるか達成時点の成績でリザルトへ進むか選べる
  • PRACTICE の記録は保存されない（自己ベストや対戦記録の対象外）
REWIND（巻き戻し）
  • 直近100手まで、いつでも1手ずつ戻したり進めたりできる
  • 盤面左のインジケータの ⟲ / ⟳ をクリック、またはキー [ / ] で操作する
  • 盤面クリア・DELETE（部分削除）・SEQUENCE の編集は手の境界ではないため、 巻き戻し履歴には積まれない
  • GAME OVER / FINISH 後のリザルト画面にも「REWIND」ボタンがあり、 そこから直接プレイへ戻れる
CYCLE PIECE（即時ツモ変化）
  • 操作中のミノ／ぷよだけを、固定サイクルの順に即座に入れ替える隠し機能。 NEXT やホールドの中身は変えない
  • 盤面右下のインジケータをクリック、またはキー [] で操作する
  • tet のサイクル順: I → T → S → Z → J → L → O（最後まで行くと I に戻る）
  • puyo は現在の COLORS 内の色のみを、軸色×子色の全組み合わせで巡回する
  • カウンタは「新しいツモが出現するたび」「巻き戻したとき」「COLORS を変更したとき」 「ホールドしたとき」にリセットされ、次の1回目は必ず先頭（tet なら I）に戻る
SETTINGS PANEL（設定パネル）
  • 盤面左の ⚙ タブから開閉する。開いている間はゲームが一時停止する
  • SPEED: 自由落下の速さ。0（既定）は自然落下なし
  • NEXT: 表示するネクスト数（1〜10）
  • HOLD（tet）: FREE（1手に何度でも使える）／ ON（通常どおり1手1回）／ OFF
  • GHOST（tet）: 接地位置プレビューの表示切替
  • COLORS（puyo）: 使用する色数。少ない色数は多い色数に含まれる並びになる
  • SEQUENCE / OJAMA / DELETE の各項目は下記の対応する節を参照
  • 盤面クリア: 盤面を全て空にする（巻き戻し履歴には積まれない）
OJAMA（おじゃま）
  • AUTO OFF（既定）: 「おじゃま送る」を押した瞬間に AMT ぶん即座に着弾する
  • AUTO ON: INTERVAL 秒ごとに自動送信し、対戦と同じ予告つき（約1.5秒後に着弾）で降る
  • AUTO OFF で着弾させた直後は、パネルを閉じるまでの間 AMT を動かすだけで 着弾ぶんをリアルタイムに増減できる（減らして0にすると投下前の盤面に戻る＝キャンセル）
  • 一度減らして消えた段は「無かったこと」になり、再び増やすとその段だけ新しい 穴で抽選し直される（減らしていない段の穴はそのまま変わらない）
  • HOLE RATE（tet のみ）: 隣り合うおじゃま行の穴が同じ列に揃う確率（10%刻み）
DELETE / 盤面クリア
  • DELETE LINES（tet）: 下から指定した本数ぶん、空でない行を消して詰める
  • DELETE PUYOS（puyo）: 上から指定した個数ぶん、空でないぷよを消す
  • おじゃまに限らず通常のブロック・ぷよも対象になる（種類を問わない）
  • 盤面クリアと同様、巻き戻し履歴には積まれない
SEQUENCE（ツモ順設定）
  • 準備画面またはゲーム中のパネルから、ツモの出現順を自分で組める
  • バッグ（枠の列）を複数用意でき、BAG ORDER（バッグの並び：LOOP／RANDOM）と SLOT ORDER（バッグ内の枠の並び：LOOP／RANDOM）を別々に設定できる
  • 枠の値は固定するか「?」（その場でランダム抽選）にできる
  • エディタは Enter または Space で確定、Esc で編集前の内容に戻して閉じる （DONE を押したときだけ保存される）
  • ゲーム中に ON / OFF / 編集確定のいずれを行っても、NEXT とツモ生成へ即座に反映される
  • OFF に戻すと、ON にする直前の NEXT・BAG（tet）・COLORS（puyo）がそのまま復元される
